# 3D Sapper

3D Minesweeper on TypeScript + Three.js + Vite.

    npm install
    npm run dev      # http://127.0.0.1:3000
    npm test         # game-logic tests (vitest)
    npm run build    # typecheck + production build

Controls: LMB open · RMB flag · MMB or LMB on a satisfied number = chord · drag LMB to orbit · wheel to zoom · R restart · M mute · Esc menu.
